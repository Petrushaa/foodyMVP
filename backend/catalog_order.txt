# Порядок в справочнике: что показывать первым.
#
# Применяется командой `python manage.py apply_catalog_order` — она же
# вызывается при старте контейнера, поэтому порядок едет вместе с деплоем
# на любое окружение.
#
# Правила:
#   * перечислять нужно только верхушку — всё, чего здесь нет, идёт следом
#     по алфавиту;
#   * у блюд пишется название, у категорий — код (slug), как в папке иконок;
#   * порядок категорий считается внутри своей оси, оси независимы;
#   * в [type]сначала идут категории блюда (фастфуд, супы, паста),
#     затем подача, диета и основа — так их и рисует интерфейс;
#   * строки после # — комментарии, пустые строки игнорируются.
#
# Команда только расставляет перечисленное и НЕ трогает остальное, поэтому
# точечные правки в админке переживают деплой. Чтобы сбросить всё к тому, что
# написано здесь, есть флаг --reset.
#
# Пример (уберите # и впишите своё):
