# Иконки справочника

Здесь лежат готовые иконки блюд и категорий — уменьшенные, по 3–8 КБ.
Отсюда они попадают в базу и на сайт.

## Как поставить иконку

**1. Положить исходник** в `icons/meals/` (или любую свою папку). Размер и формат
любые: команда всё уменьшит. Имя файла — **ключ записи**:

- у блюда это название: `Бургер.jpeg`
- у категории — код: `japanese.jpeg`

**2. Подготовить** — уменьшить и разложить:

```bash
cd backend
python manage.py prepare_icons --from ../icons/meals              # блюда
python manage.py prepare_icons --from ../icons/cuisines --kind cuisine
python manage.py prepare_icons --from ../icons/types --kind type
```

Что не совпало с справочником, команда назовёт и подскажет похожее:

```
«Цезарь» в справочнике не найдено — похоже на «Салат Цезарь»?
```

Тогда переименуйте исходник и запустите снова. Флаг `--dry-run` показывает,
что будет сделано, ничего не записывая.

**3. Залить в базу:**

```bash
python manage.py import_icons
```

Уже загруженные пропускаются. Обновили картинку — `--replace`.

**4. Проверить, что осталось:**

```bash
python manage.py import_icons --missing
```

Печатает недостающие записи с точными именами файлов, по папкам.

## Что происходит дальше само

На проде эти команды вызываются при старте контейнера, поэтому после
`git push` иконки приезжают без ручных шагов. Локально шаг 3 нужно
запускать самому — там Django поднимается напрямую, мимо entrypoint.

Пока картинки нет, показывается эмодзи. Поэтому заливать можно частями:
интерфейс не ломается на полпути.

## Требования к картинкам

- **Формат:** любой на входе, на выходе всегда webp 256×256.
  SVG не принимается: Pillow его не проверяет, а внутрь можно вложить скрипт.
- **Фон:** белый или сплошной — иконка растягивается на всю плитку целиком.
- **Исходники** в репозиторий не едут (`icons/` в `.gitignore`), едут только
  уменьшенные копии отсюда.
