# Иконки справочника

Сюда кладутся картинки блюд и категорий, отсюда они заливаются в базу командой:

```bash
python manage.py import_icons            # залить недостающие
python manage.py import_icons --dry-run  # посмотреть, что будет
python manage.py import_icons --replace  # перезалить уже загруженные
```

Раскладка — имя файла это **ключ записи**, а не подпись:

```
dish-types/Бургер.png          ← по названию блюда
taxons/cuisine/japanese.png    ← по оси и коду категории
taxons/form/sushi.png
taxons/format/fastfood.png
taxons/diet/vegan.png
```

Код категории уникален только внутри своей оси, поэтому оси разложены по папкам.

**Формат:** PNG или WebP, 128×128 (на ретине не мылится). SVG не принимается:
Pillow его не проверяет, а внутрь SVG можно вложить скрипт, который выполнит браузер.

Записи без картинки продолжают показывать эмодзи — заливать можно постепенно.
Что осталось, видно в админке фильтром «Иконка → Нет».
